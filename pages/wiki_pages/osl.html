OSL

OSL is a language based on JavaScript and Go. OSL has relatively simple syntax compared to both of the languages they are based off of. The docs for OSL can be found here. OSL comes in 2 flavors:

  • OSL.js: The JavaScript-based version of OSL, used primarily within OriginOS.
  • OSL.go: The Go-based version of OSL, used primarily for server backends.

OSL.js

Also known as: OriginOSL, OSL Legacy

This is the version of OSL that is used to create apps within OriginOS. A lot of OriginOS is written using OSL, including all the system apps. As the name implies, this version of OSL was primarily made using JavaScript.

OSL.go

Also known as: GOSL, OSL

This is the version of OSL that is used as the backend language for a good chunk of Rotur services. As the name implies, this version of OSL was made using Golang, or Go for short. According to Mistium, this version of OSL is officially the main version of OSL, as of May 3, 2026.

OSL.js vs. OSL.go

Overtime, Mistium has made an effort to bring OSL.js and OSL.go up to speed with one another. Outside of the obvious differences mentioned above, there are still a few key differences between the two, such as:
- OSL.js has properties that allow it to easily control properties of OriginOS apps, unlike OSL.go
- Given that OSL.go is written in Go, this version is better tailored for server backends, unlike OSL.js. OSL.go also comes with the benefit of being significantly faster than OSL.js too, given Go is faster than JavaScript.
