originOS

Link: https://origin.mistium.com

Overview

OriginOS is where it all began. OriginOS is a scratch-based web OS, home to a programming language commonly seen and used within the Rotur community: OSL. For most newcomers to the greater Rotur community, originOS is a common way people interact with Rotur (that or using roturBOT). OriginOS allows you to run OSL apps and programs, which can include games.

OSL

Main article: OSL

OSL is the programming language all OriginOS programs are coded in. This includes apps, the dock, and even the theme handlers. While the main version of OSL is Go-based, OriginOS uses a JS-based flavor of it for browser compatibility.

ICN

Main article: ICN

While ICN today is attributed to Rotur as a whole, ICN began on originOS, and is still originOS's primary way of rendering vector-esque elements, such as all the badges on peoples' profiles. The docs for ICN can be found here. Various renderers and editors exist for ICN too, but the most common and accessible one as of now is OriginOS's studio app, which has built-in support for real-time ICN editing. However, as of Rotur Assistant 1.2, Rotur Assistant's provided ICN editor and renderer can be found here, complete with its own version of the docs.
