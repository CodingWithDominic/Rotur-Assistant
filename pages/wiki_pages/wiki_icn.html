ICN

For Rotur Assistant's ICN editor, see ICN editor.

Overview

ICN is Rotur's version of SVG, being a lightweight, scalable icon format. The syntax to create ICNs is fairly simple, taking on an assembly style syntax of command 1 2 3. The docs for ICN can be found here. Various renderers and editors exist for ICN too, but the most common and accessible one as of now is OriginOS's studio app, which has built-in support for real-time ICN editing. However, as of Rotur Assistant 1.2, Rotur Assistant's provided ICN editor and renderer can be found here, complete with its own version of the docs.

History

While ICN today is attributed to Rotur as a whole, ICN began on originOS, and is still originOS's primary way of rendering vector-esque elements, such as all the badges on peoples' profiles. ICN is still used today in various places, such as The official OriginChats client to render badges on profiles.
