The Rotur SMP

Server IP: mc.rotur.dev

Overview

The Rotur SMP is a Minecraft SMP that people of the Rotur community infrequently play on. The SMP is hosted by Milodev123, and it runs on Paper 1.21.1. The server has some quality-of-life commands to make players' lives easier, such as /home and /tpa. An unintended side effect of the graves plugin the server uses, is that players can teleport back to their graves via a menu, thus adding another quality-of-life thing. Like everything else mentioned in Rotur Economy, selling in-game items for Rotur credits can be a good income source, though it's not very effective since people today play on the SMP infrequently.

History

Prior to the Rotur SMP, there was the origin SMP. The origin SMP only lasted for 5 days, since someone speedran and beat the game behind everyone else's backs. As a result of this, the end was locked for a long time when the Rotur SMP first started. Today, the end is unlocked, though the dragon fight irself is currently inaccessible due to barriers placed around the end fountain.

How to join

While the server's IP is provided at the top of this page, there's an extra requirement in order to join the Rotur SMP. As of now, the only method of satisfying that requirement is to somehow find your way into the OriginOS Discord server (invites today are scarce, since as mentioned on the wiki regarding the Discord, the OriginOS Discord server is now a read-only server in favor of OriginChats), and then somehow get the "MINECRAFT!!!!" role. It used to be available through onboarding, but since onboarding was removed in the process of making the OriginOS server read-only, you're gonna have to ask someone who is still an admin in the Discord server to give you the role manually.
